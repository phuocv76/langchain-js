# Feature Requests

We track feature requests in the product roadmap. When a customer asks for a new capability:

1. Acknowledge the request and thank them for the feedback.
2. Share whether a similar feature already exists.
3. Explain that the request has been logged for the product team.

Common topics:

- API webhooks
- SSO / SAML login
- Custom export formats

Do not promise delivery dates unless confirmed in official release notes.
